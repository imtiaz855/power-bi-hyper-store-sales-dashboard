# power-bi-hyper-store-sales-dashboard
Interactive sales dashboard built using Microsoft Power BI.
📊 Power BI Hyper Store Sales Dashboard

📌 Project Overview

This project features an interactive sales dashboard built using Microsoft Power BI to analyze business performance and generate meaningful insights.

🎯 Dashboard Features

* Revenue and Net Profit Analysis
* Monthly Revenue and Sales Performance
* Top 5 Best-Selling Products
* Top 5 Worst-Selling Products
* Revenue by Customer Segment
* Revenue by Product Category
* Units Sold and Unit Cost Analysis
* Interactive Filters for Data Exploration

🛠️ Tools & Technologies

* Microsoft Power BI
* Data Visualization
* Business Intelligence

💡 Project Objective

The objective of this project is to transform sales data into meaningful visual insights that support business analysis and data-driven decision-making.
